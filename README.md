# Rustz0ne Media

Полные файлы обоев для https://rustz0ne.netlify.app/.

## Условия использования

Обои разрешено скачивать и использовать лично: на компьютере, телефоне и в Wallpaper Engine. Перепродажа файлов и включение их в платные наборы запрещены. Права на Rust и материалы Facepunch остаются у их владельцев.

Файлы публикуются в Releases; один релиз на обои, тег совпадает с id. JPG — статичные обои, MP4 — живые. Увеличение разрешения не добавляет детализации; увеличенные демо-версии помечены на сайте.

Исходники, текстуры и секреты здесь не публикуются.
